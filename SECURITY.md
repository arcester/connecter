# Security

Please **do not** open a public issue for security problems.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/arcester/connecter/security/advisories/new), or by email to [dev@arcesaez.com](mailto:dev@arcesaez.com) if you don't use GitHub. Include the macOS and Connecter versions and the steps to reproduce. You'll get an answer as soon as possible.

---

Por favor, **no** abras una incidencia pública para problemas de seguridad. Comunícalos en privado mediante el enlace de arriba o escribiendo a [dev@arcesaez.com](mailto:dev@arcesaez.com) si no usas GitHub.
